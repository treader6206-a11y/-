# Omni — اکوسیستم هوشمند خدمات و هویت بصری

این مخزن پیش‌نویس اولیهٔ مستندات پروژهٔ Omni است: یک اکوسیستم هوشمند چندحوزه‌ای که دستیار هوشمند، شبکهٔ متخصصان و بازار خدمات را ترکیب می‌کند و هر حوزه زیرِ یک هویت مادر بصری سازمان‌دهی می‌شود.

## چشم‌انداز

Omni هدف دارد تا یک پلتفرم جهانی، امن و مقیاس‌پذیر بسازد که انسان، متخصص و کسب‌وکار را به کمک هوش مصنوعی گرد هم آورد تا خدمات تخصصی، همکاری و فرصت‌های اقتصادی را در یک تجربهٔ یکپارچه ارائه دهد.

## اصول کلیدی

- هویتِ سه‌لایهٔ بصری: برند مادر Omni + هویت‌های حوزه‌ای + صفحات و تبلیغات شخصی‌سازی‌شده.
- هر حوزه: رنگ‌بندی اختصاصی، سبک تصویری اختصاصی، آیکون‌ها، تصاویر 3D، ویدیو و انیمیشن.
- هستهٔ مشترک فناوری: کاربران، پروفایل‌ها، Marketplace عمومی، Omni Match AI، پرداخت، پیام‌رسان.
- هر حوزه بازار خدمات اختصاصی دارد (ثبت آگهی، مدیریت رسانه، تقویم، پرداخت، پیام‌رسان).
- قانون طلایی Omni — هر ویژگی باید 7 سؤال کلیدی محصولی و امنیتی را پاسخ دهد.

## خروجی‌های پیشنهادی (قابل تحویل)

1. Omni Brand Identity Book v1.0 (لوگو، پالت رنگ، فونت، سبک سه‌بعدی، نمونه‌ صفحات)
2. Design System سه‌لایه و UI Kit (tokens، کامپوننت‌ها، الگوهای حوزه‌ای)
3. PRD و نمودار مدل دادهٔ Marketplace
4. نسخهٔ پایهٔ Omni Match AI (متن+تصویر embeddings + LTR)
5. مستندات امنیت و انطباق (MFA, KYC, GDPR و سیاست‌های ضدتقلب)

## پیشنهاد MVP و نقشهٔ راه خلاصه

- فاز 0 (Foundation): تعیین دامنهٔ پایلوت، Brand Book اولیه، مدل دادهٔ Marketplace.
- فاز 1 (Core Marketplace): ثبت آگهی، پروفایل‌ها، آپلود رسانه، جستجو و فیلتر، پیام‌رسان پایه، پرداخت پایه.
- فاز 2 (Omni Match AI): مدل‌های برداری برای متن/تصویر و رتبه‌بندی پیشنهاد.
- فاز 3 (دامنه‌سازی): قالب‌های حوزه‌ای، صفحات متخصص، تبلیغات هدفمند.

## معیارهای موفقیت (KPI)

- زمان تا اولین لیست منتشرشده
- نرخ تبدیل بازدید→تماس/رزرو
- CTR پیشنهادهای Omni Match در مقایسه با baseline
- NPS و میزان گزارش تخلف

## نیازمند تصمیم شما

لطفاً برای شروع، به سوالات زیر پاسخ دهید:

1. کدام حوزه را برای پایلوت انتخاب می‌کنید؟ (مثلاً: Tourism, Home, Auto, Health)
2. بازار هدف اولیه چه کشور(ها) یا منطقه(هایی) است؟
3. پرداخت و تماس صوتی/تصویری را از ابتدا بخواهید یا در فاز بعدی؟
4. آیا لوگو/هویت تصویری اولیه دارید یا می‌خواهید از صفر طراحی شود؟
5. سطح تأیید هویت برای متخصصان در فاز اولیه چگونه باشد؟ (بدون KYC / KYC ساده / KYC کامل)
